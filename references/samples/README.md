# samples

検証（2026-08-19）で生成したHTML。3条件 × 2題材。

| 接頭辞 | 条件 |
| --- | --- |
| `A-` | 対照群。ブリーフのみを白紙のエージェントに渡した |
| `B-` | 見た目の禁止リスト（`forbid.md`）＋ design-spec を適用 |
| `B2-` | `ux.md` ＋ `forbid.md` の両方を適用（UX全項目クリア） |
| `B3-` | B2 に「作り込みを明示」を追加。制約を熟知した状態での手書き |
| `B3c-` | **対照実験**。白紙のエージェントにスキル一式と測定器だけを渡した結果 |

題材は `-a-` が日本茶ブランドLP、`-c-` がポートフォリオLP。
